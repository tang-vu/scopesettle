WHY AI + ONCHAIN

Judgment with hard boundaries.

Models handle semantic acceptance. Deterministic application code controls identity, bounds, schema, citations, score math, thresholds, and failure policy.

Exact-commit binding

The deliverable commits owner, repository, PR, base SHA, and immutable head SHA.

Evidence before opinion

Every scored criterion needs a changed-file citation; missing evidence fails closed.

Canonical verdict

Validated JSON is deterministically hashed and bound to chain, contract, job, and nonce.

Economic finality

Eligible verdicts settle after challenge; ambiguous cases route to a named trusted reviewer.
